# Cursor Workspace Image Download

Help the Android app download and display images generated by Cursor AI models (Grok, etc.) from the cloud agent's `artifacts/` folder. Trigger when the user mentions image generation, downloading pictures from Cursor workspace, or shows "Generated again. Also saved as 'filename.png' in your workspace" text in chat.

## Role

You are an expert at wiring Cursor Cloud Agent artifact downloads into the Cursor Chat Android app. You know the exact flow: SSE streaming → polling artifacts API → presigned S3 download → local cache → MessageBubble display.

## Instructions

### When to apply this skill

Apply when:
- User asks about displaying AI-generated images in the chat app
- Response text contains filenames like `saved as 'filename.png'` or mentions workspace files
- User wants to wire up image downloads for a new Cursor Chat project
- You need to understand how artifacts flow from Cursor's server to the phone

### What you need to know first

**The core problem:** Cursor AI models generate images server-side on Cursor's workspace. The SSE response contains **only text** mentioning the filename — no image bytes, no data URLs, no markdown syntax.

```
User: "generate a photorealistic kitchen"
Agent reply (text only): "Generated again. Also saved as 'photorealistic-kitchen-v3.png' in your workspace..."
```

**The solution:** Poll `GET /v1/agents/{agentId}/artifacts` for new image files, download via presigned S3 URLs, cache locally, attach to assistant message entity.

### Implementation checklist (follow in order)

1. **Verify infrastructure exists** — Check these are present:
   - `CursorAgentsClient.kt` has `listArtifacts()`, `getArtifactDownloadUrl()`, `downloadBytes()`
   - `Dtos.kt` has `ListArtifactsResponse`, `ArtifactItem`, `DownloadArtifactResponse`
   - `ImageCache.kt` has `saveDownloadedBytes()`, `localPathForArtifact()`, `artifactPathForLocal()`, `isImageArtifactPath()`

2. **Add sync call in ChatViewModel** — In `startStreaming()` after SSE completes:
   ```kotlin
   val artifactImages = runCatching {
       repository.syncImageArtifacts(
           conversationId = conversationId,
           runId = runId,
           assistantText = accumulatedAssistant
       )
   }.getOrDefault(emptyList())
   ```

3. **Implement syncImageArtifacts() in ChatRepository** — The full flow:
   ```kotlin
   suspend fun syncImageArtifacts(
       conversationId: String,
       runId: String?,
       assistantText: String = ""
   ): List<String> {
       val apiKey = apiKeyStore.getApiKey() ?: return emptyList()
       val agentId = getConversation(conversationId)?.agentId ?: return emptyList()

       // Poll artifacts with retry (4 attempts, 2s apart)
       var imageArtifacts: List<ArtifactItem> = emptyList()
       repeat(ARTIFACT_POLL_ATTEMPTS) { attempt ->
           val listed = agentsClient.listArtifacts(apiKey, agentId).getOrNull()
           imageArtifacts = listed?.items
               ?.filter { isImageArtifactPath(it.path) }
               ?.sortedByDescending { it.updatedAt.orEmpty() }
               .orEmpty()
           if (imageArtifacts.isNotEmpty()) return@repeat
           if (attempt < ARTIFACT_POLL_ATTEMPTS - 1) delay(ARTIFACT_POLL_DELAY_MS)
       }

       if (imageArtifacts.isEmpty()) return emptyList()

       val newlyDownloaded = mutableListOf<String>()
       for (artifact in imageArtifacts) {
           // Skip already-cached
           val existingLocal = imageCache.localPathForArtifact(conversationId, artifact.path)
           if (existingLocal != null) continue

           // Download
           val url = agentsClient.getArtifactDownloadUrl(apiKey, agentId, artifact.path).getOrNull()?.url ?: continue
           val bytes = agentsClient.downloadBytes(url).getOrNull() ?: continue
           val cached = imageCache.saveDownloadedBytes(conversationId, artifact.path, bytes)
           newlyDownloaded += cached.localPath
       }

       // Attach to assistant message entity
       if (newlyDownloaded.isNotEmpty()) {
           saveAssistantMessage(
               conversationId = conversationId,
               text = "",
               runId = runId,
               status = "FINISHED",
               imagePaths = newlyDownloaded
           )
       }

       // Background: ask agent to delete cloud files (optional cleanup)
       CoroutineScope(SupervisorJob() + Dispatchers.IO).launch {
           requestArtifactCleanup(conversationId, newlyDownloaded.map { artifactPathForLocal(conversationId, it) }.filterNotNull())
       }

       return newlyDownloaded
   }
   ```

4. **Inject artifacts/ instruction into agent prompts** — In `buildAgentPrompt()`:
   ```kotlin
   if (looksLikeImageGenerationRequest(base)) {
       return base.trimEnd() +
           "\n\n[App requirement: If you generate or export any image files, save them under " +
           "the artifacts/ directory (example: artifacts/kitchen.png). Only files in artifacts/ " +
           "can be downloaded and shown in this mobile chat app. Do not put them only in the " +
           "workspace root.]"
   }
   ```

5. **Display in MessageBubble** — The `imagePaths` list is already rendered by Coil AsyncImage. No changes needed to the UI layer.

### Edge cases to handle

| Case | Mitigation |
|------|-----------|
| Agent writes files after SSE closes | Poll loop: 4 attempts × 2s = 8s total wait |
| Presigned URL expires (~15min) | Retry on next sync; app won't crash, shows nothing |
| Already-cached artifacts | localPathForArtifact() returns cached path, skips download |
| No agentId for conversation | Early return emptyList() |
| Cloud workspace fills up | requestArtifactCleanup() runs in background coroutine |
| Large images (>15MB) | Direct byte download (not base64), scaled to 1568px for upload |
| Multiple concurrent generations | sortedByDescending { updatedAt } shows newest first |

### What NOT to do

- **Do NOT** try to parse data:image/base64 from SSE responses — Cursor doesn't send any
- **Do NOT** add new API endpoints — the artifacts API already exists
- **Do NOT** block the chat UI waiting for artifact cleanup — always launch in background coroutine
- **Do NOT** forget to append the `artifacts/` instruction to image generation prompts

3. Did `getArtifactDownloadUrl()` return a valid URL?
4. Did `downloadBytes()` succeed? Check logs for network errors
5. Are the paths attached to MessageEntity.imagePaths? (check saveAssistantMessage call)
