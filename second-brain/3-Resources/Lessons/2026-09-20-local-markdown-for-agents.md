# Prefer local Markdown for agent-readable memory

## Context
Wanted a durable “second brain” for lessons across machines and chats.

## Lesson
- **Agents (Cursor)** read local files reliably; OneDrive Graph list/search alone is weak for full-doc recall.
- Keep vault as plain Markdown on disk; optionally sync the folder with OneDrive for backup/phone.
- Keep **repo `memory-bank/`** for project tip status; keep **Second Brain** for cross-project lessons.
